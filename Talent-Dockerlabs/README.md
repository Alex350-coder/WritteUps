# Talent Dockerlabs Vulnerability Exercise

## Español

**Descripción:**
Este laboratorio guía al usuario a través del compromiso de una instalación de WordPress vulnerable. Se exploran vectores comunes: credenciales débiles, plugins inseguros, edición de código desde el panel, y permisos de `sudo` mal configurados. El objetivo es lograr acceso administrativo y escalar hasta root en un entorno Dockerizado.

**Requisitos:**
- Máquina con Docker para levantar el contenedor meta.
- Herramientas básicas de pentesting: `nmap`, `netcat`, `python3`, Kali Linux o distribución similar.
- Permiso para modificar plugins de WordPress y ejecutar comandos en la VM.

**Documentación:**
- Manual completo (español): `Talent.md`
- Full guide (English): `TalentEn.md`
- Quick reference: `QuickStart.md`

Mantenga este repositorio como referencia para ejercicios de hacking ético y pruebas de seguridad en entornos controlados.

## English

**Description:**
This lab walks the user through compromising a vulnerable WordPress installation. Common vectors are explored: weak credentials, insecure plugins, dashboard code editing, and poorly configured `sudo` permissions. The goal is to gain administrative access and escalate to root within a Dockerized environment.

**Requirements:**
- Docker-capable machine to run the target container.
- Basic pentesting tools: `nmap`, `netcat`, `python3`, Kali Linux or similar distro.
- Ability to modify WordPress plugins and execute commands on the VM.

**Documentation:**
- Complete walkthrough (Spanish): `Talent.md`
- Full guide (English): `TalentEn.md`
- Quick reference: `QuickStart.md`

Keep this repository as a reference for ethical hacking exercises and security testing in controlled setups.
