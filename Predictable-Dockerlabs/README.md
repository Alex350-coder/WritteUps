# Predictable — Dockerlabs

ES / Español

Descripción:

Este repositorio contiene el laboratorio "Predictable", orientado al análisis y explotación de un servicio HTTP que revela una secuencia numérica predecible (LCG). El objetivo del laboratorio es practicar técnicas de reconocimiento, ingeniería inversa, explotación de entornos restringidos (`pyjail`) y escalada de privilegios a través de reglas de `sudo` mal configuradas.

Requisitos:

- Máquina objetivo con los servicios habilitados (SSH y HTTP en los puertos indicados).
- Herramientas: `nmap`, `radare2`, `ssh`, y el script de análisis LCG (p. ej. Ghxstsec).

Contenido útil:

- `Predictable.md` — Descripción ampliada del laboratorio y recomendaciones (español).
- `PredictableEn.md` — Traducción profesional al inglés.
- `QuickStart.md` — Resumen de pasos rápidos en español e inglés.

Uso rápido:

Consulte `QuickStart.md` para los comandos de reproducción rápida; para una explicación detallada lea `Predictable.md`.

EN / English

Description:

This repository contains the "Predictable" lab focused on analyzing and exploiting an HTTP service that exposes a predictable numeric sequence (LCG). The lab exercises reconnaissance, reverse engineering, escaping restricted Python environments (pyjail), and privilege escalation via misconfigured `sudo` rules.

Prerequisites:

- Target machine with services enabled (SSH and HTTP on the indicated ports).
- Tools: `nmap`, `radare2`, `ssh`, and an LCG analysis script (e.g., Ghxstsec).
