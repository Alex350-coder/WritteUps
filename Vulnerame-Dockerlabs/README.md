
# Vulnerame — Practical Exploitation Lab / Laboratorio práctico de explotación

## Description / Descripción

- EN: Vulnerame is a hands-on lab that demonstrates a complete exploitation chain against a target running a vulnerable Joomla installation, MySQL, and SSH. The lab covers reconnaissance, CVE exploitation to recover credentials, password cracking, reverse shell execution, and final privilege escalation to root.
- ES: Vulnerame es un laboratorio práctico que demuestra una cadena completa de explotación contra un objetivo con una instalación vulnerable de Joomla, MySQL y SSH. El laboratorio cubre reconocimiento, explotación de CVE para recuperar credenciales, cracking de contraseñas, ejecución de reverse shell y escalada final a root.

## Requirements / Requisitos

- EN: A controlled lab environment (VM or container), permission to test, and a Linux attacker host with the following tools: `nmap`, `gobuster`, `mysql-client`, `john`, `nc`, `hydra`, and typical development tools.
- ES: Entorno de laboratorio controlado (VM o contenedor), autorización para realizar pruebas y una máquina atacante Linux con las herramientas: `nmap`, `gobuster`, `mysql-client`, `john`, `nc`, `hydra`, y herramientas de desarrollo habituales.
